Added C++ support to the debugger. C++ compilation units now resolve their function names (demangled to the fully-qualified signature, e.g. `sensors::Thermometer::read() const`), read primitive variable values (including `bool` as `true`/`false`), and render classes (`DW_TAG_class_type`) with inherited base-class members, references (as `T&`), and enums (scoped and unscoped) — instead of falling back to the "unsupported language" handler.
